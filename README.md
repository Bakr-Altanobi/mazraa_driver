# مزرعتي للسائق

تطبيق Flutter عربي أولًا لسائقي ومندوبي منصة مزرعتي. يتصل مباشرة بواجهة الإنتاج `https://mzraa.runasp.net/` ويغطي تسجيل الدخول، استعادة الجلسة وتجديدها، ملف السائق، الشحنات وتحديث حالاتها وموقعها، المحفظة، الإشعارات، اللغة والمظهر.

## أبرز خصائص النسخة الحالية

- هوية بصرية مستخرجة من تطبيق العميل: أخضر داكن، برتقالي، خلفيات عاجية، بطاقات مستديرة وظلال هادئة.
- العربية RTL والإنجليزية LTR، مع Light/Dark/System themes.
- جلسة JWT محفوظة في `flutter_secure_storage` وتجديد Token أحادي الطلب.
- تحقق إضافي من `/api/Drivers/{userId}` لأن استجابة الإنتاج الحالية لا ترسل الدور.
- دورة الشحنة المدعومة فعلًا، تحديث الموقع، والتعامل الصريح مع 400/401/403/404/409/422/429/500/503.
- محفظة ومعاملات وإشعارات من السيرفر الحقيقي، بلا بيانات نجاح وهمية.
- 48 وجهة تصميم مرتبطة بأدوات فعلية، مع 34 صفحة عمل و14 نموذجًا، وإثباتات الصور والتوقيع وQR والتحصيل الكامل.
- خريطة OpenStreetMap فعلية افتراضيًا وخيار Google Maps مهيأ بالمفتاح الموجود، مع مسارات السيرفر والملاحة الخارجية. فحص المحاكي أثبت أن المفتاح الحالي غير مصرح لحزمة السائق.
- راجع [تغطية الشاشات والعقود](docs/DRIVER_APP_SCREEN_COVERAGE_20261021.md) للتفاصيل والخدمات التي تنتظر دعم السيرفر.

## التشغيل السريع

```powershell
flutter pub get
flutter run --dart-define=ENABLE_GOOGLE_MAPS=true
```

بيانات الاختبار لا تُضمّن داخل النسخة الإنتاجية. يمكن تمريرها محليًا فقط:

```powershell
flutter run --dart-define=DRIVER_TEST_EMAIL=... --dart-define=DRIVER_TEST_PASSWORD=...
```

راجع [دليل البناء](docs/BUILD_AND_RUN.md)، [خريطة الـAPI](docs/API_INTEGRATION_MATRIX.md)، و[فجوات السيرفر](docs/KNOWN_BACKEND_GAPS.md) قبل اختبار دورة التسليم.

## البنية

- `lib/app`: Bootstrap، Router، إعدادات اللغة والمظهر.
- `lib/core`: العقود، الشبكة، التخزين الآمن، الثيم، والأدوات.
- `lib/features`: المصادقة، الرئيسية، الشحنات، المحفظة، الإشعارات، الحساب.
- `lib/shared`: عناصر الواجهة والخريطة المشتركة.
- `assets`: الشعار والرسوم والـmarkers الأصلية.
- `docs`: وثائق التكامل والاختبار والتسليم.

Package IDs: Android وiOS يستخدمان `com.mazraa.driver`.
